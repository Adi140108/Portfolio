# Adithya | Developer Portfolio

A developer portfolio built with modern vanilla HTML5, CSS3, and JavaScript, featuring real-time GitHub telemetry, interactive case studies, responsive glassmorphism, and verified project showcases.

Live Demo: [https://codewars-4-0.vercel.app/](https://codewars-4-0.vercel.app/) &bull; GitHub: [@Adi140108](https://github.com/Adi140108)

---

## 🚀 Features

- **Cyber Obsidian & Solar Amber Design**: Tailored 60-30-10 color hierarchy with subtle glassmorphism and WCAG AAA contrast.
- **Dynamic Specialty Typewriter**: Reactive headline cycling through Full-Stack, Flutter, and AI development specialties.
- **Featured Projects Showcase**: In-depth case studies for CODEWARS 4.0, DayFlow (Odoo × NMIT 2026), IP-Sakti (SIH PS 45), MediMind-Ai, Sehat-Setu, and Nexora Dashboard.
- **Live GitHub Explorer**: Real-time integration with the GitHub REST API (`@Adi140108`) supporting instant search, multi-language filtering, and cached fallback.
- **Verified Achievements Timeline**: Authentic milestones covering SIH Internal Qualification, GDG TechSprint Hackathon Top 10, Nexora Club, and InAmigos Foundation.
- **Asynchronous Contact Form**: Formspree integration with client-side validation, clipboard instant copy, and pre-filled email fallback.
- **Responsive & Accessible**: Mobile-first design (360px–1440px), keyboard navigable, and respects `prefers-reduced-motion`.

---

## 🛠️ Stack

- **Markup**: Semantic HTML5 (ARIA landmarks, OpenGraph metadata)
- **Styling**: Vanilla CSS3 (Custom design tokens, CSS Grid & Flexbox, micro-animations)
- **Scripting**: Vanilla JavaScript (Async GitHub API polling, DOM filtering, modal manager)
- **Icons & Typography**: Font Awesome 6.5, Google Fonts (Archivo, Space Grotesk, JetBrains Mono)
- **Contact Backend**: Formspree

---

## 💻 Local Development

Run the portfolio locally with any lightweight static server:

```bash
# Using Node.js serve
npx serve . -l 5173

# Or using Python 3
python -m http.server 5173
```

Open `http://localhost:5173` in your browser.
